# 든든 화면 개편 적용

승인한 `ui-concept-20261028-v1.png`의 시작 화면, 결과 화면과 설정 화면을 React에 적용했습니다.

- 비로그인 상태에서는 저장된 게스트 프로필이 있어도 로그인과 게스트 선택을 먼저 보여줍니다. 게스트를 선택하면 이전 기록을 이어갈 수 있습니다.
- 로그인 상태의 회원은 프로필을 입력하거나 기존 식사 입력 화면으로 이어집니다.
- 계정 정보, 프로필 수정, 기록 조회와 로그아웃은 우측 상단 설정으로 모았습니다.
- 결과는 열량 요약, 영양소별 목록, 실제 API의 추천 상품, 저장 동작 순서입니다. 추가 영양소와 계산 기준은 펼쳐서 확인합니다.
- 미확인 성분은 점선으로 표시하고 철분과 나트륨은 섭취량만 보여줍니다. 비타민 D의 충분섭취량 미달은 부족으로 표시하지 않습니다.
- 저장 후에도 결과를 유지하며, 날짜별 기록에서 각 식사의 확정 당시 결과를 펼쳐볼 수 있습니다.

검증은 프론트 단위 테스트 16개, 모의 API를 사용하는 브라우저 검사 5개, 공개 주소에서 실제 상품을 사용하는 브라우저 검사 1개를 통과했습니다. ESLint, TypeScript 검사와 운영 빌드도 통과했습니다. 320px 모바일, 390px 모바일과 1440px 데스크톱에서 가로 넘침을 확인했습니다.

`deployed-ui-20261028/`의 이미지는 공개 서비스에서 별도 브라우저와 검증용 게스트 프로필로 촬영한 실제 화면입니다. 서버 회원이나 식사 데이터는 만들지 않았습니다.
